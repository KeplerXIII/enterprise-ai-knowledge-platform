**Тема:**
Корпоративная RAG-платформа интеллектуального поиска и анализа документов с использованием больших языковых моделей (LLM)

**Описание:**
Проект представляет собой прикладную систему, состоящую из двух ключевых компонентов: корпоративного поисковика по базе знаний и модуля анализа документов. Платформа предназначена для упрощения поиска, обработки и анализа внутренних документов организации (нормативной базы, регламентов, служебной информации).

Тема выбрана в связи с актуальными рабочими задачами, связанными с обработкой большого объема корпоративной документации и необходимостью повышения эффективности доступа к знаниям внутри организации.
